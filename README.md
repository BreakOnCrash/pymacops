# pymacops

macOS automation helpers for window control, input, image matching, and OCR.

## Permissions

To use this tool, you need to grant the following permissions to the Terminal app running your scripts:

- **Accessibility**: Required for input simulation (mouse and keyboard).
- **Screen Recording**: Required for screenshots and window information.

To grant these permissions:

1. Go to System Settings > Privacy & Security.
2. Under "Accessibility", add and enable your Terminal app (e.g., Terminal, iTerm, or Kitty).
3. Under "Screen Recording", add and enable your Terminal app.
